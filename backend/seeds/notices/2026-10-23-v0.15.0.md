# v0.15.0 업데이트 — 단독 서버도 MCP 를 밖에서 받고, 화면 주소에 접두어가 붙습니다

■ 바뀐 것
- 단독 서버도 MCP 를 기본으로 밖에서 받습니다. 전에는 서버 안에서만 받아 사람들의 Claude · HWAX 게이트웨이가 붙지 못했습니다. 인증은 토큰으로 하므로 드러나는 면은 앱 포트와 같습니다.
- 화면 주소가 단독 · 이중화 모두 `http://<서버>:<포트>/<slug>/` 입니다(HWAX 포털의 주소 모양과 같습니다). 접두어 없는 옛 주소와 게이트웨이 · MCP 가 부르는 주소도 그대로 됩니다.

■ 확인해 주십시오
- 운영자: `sudo ./deploy.sh update` 한 번이면 둘 다 반영됩니다. 화면 주소 접두어를 이미 적어 둔 설치(빈 값 = 루트 포함)는 건드리지 않습니다.
- 이전 판 단독 서버의 MCP 는 다음 update 때 밖으로 열리고 그렇게 알립니다. 서버 안에서만 받으려면 `sudo MCP_HOST=127.0.0.1 ./deploy.sh update` 로 올리십시오. 직접 고른 값은 설치 기록에 남아 다음 update 도 지킵니다.
- 갱신 뒤 쿠키 경로가 바뀌어 한 번 다시 로그인해야 합니다.
