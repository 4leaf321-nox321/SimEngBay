# v0.8.0 업데이트 — CAD 가 적은 큰 변형을 읽고, CalculiX 가 강체 지지점의 마찰을 접촉으로 풉니다

■ 새로 생긴 것
- 결과 요약에 큰 변형을 켰는지와 그 값이 어디서 왔는지(CAD 값인지 직접 고른 값인지)를 적습니다.

■ 바뀐 것
- CAD 조건의 큰 변형 · 초기 부단계 수를 CalculiX · Ansys 둘 다 읽습니다. 전에는 CAD 가 큰 변형이라 적은 시험(굽힘 · 핀 베어링 · 이음 · 비틀림)도 선형으로 풀렸습니다.
- 새 작업 창이 큰 변형 칸을 CAD 값으로 미리 채웁니다(「CAD 가 적은 값」). 칸을 비우면 CAD 값을 따릅니다. 부단계 수는 비선형 해석일 때만 씁니다.
- CalculiX 가 강체 지지점(굽힘 시험의 롤러 · 누름쇠, 핀 베어링의 핀)과의 마찰을 접촉으로 풉니다. 전에는 붙여서 풀어 판이 미끄러지지도 돌지도 못했고, 보드 굽힘 반력이 손셈의 16배로 나왔습니다. 이제 Ansys 와 0.1 % 안에서 맞습니다.
- 강체 지지점에 마찰 접촉이 있어도 CalculiX 에서 「큰 변형」 을 켤 수 있습니다.

■ 확인해 주십시오
- CAD 가 큰 변형을 적은 설계점을 이전 판으로 푼 작업은 선형으로 풀렸습니다. 차이가 클 수 있으니(겹치기 이음 반력 3.8 N → 4,528 N) 다시 돌리십시오.
- 강체 지지점에 마찰 접촉이 있는 CalculiX 작업(굽힘 · 핀 베어링 등)도 다시 돌리십시오.
- CalculiX 에서 양쪽이 모두 강체인 접촉은 막습니다.
