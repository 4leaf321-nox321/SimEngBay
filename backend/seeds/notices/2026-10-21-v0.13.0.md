# v0.13.0 업데이트 — HWAX 포털로 로그인하고, HWAX 게이트웨이가 사용자를 대신해 부릅니다

■ 새로 생긴 것
- 로그인 화면에 「HWAX 포털로 로그인」 이 생겼습니다. 포털에서 넘어오면 비밀번호 로그인과 같은 세션이 열립니다.
- 포털로 처음 들어온 사람은 가입 신청(승인 대기)으로 들어옵니다. 관리 화면의 계정에서 희망 부서가 없는 신청을 「승인」 하면 부서를 묻습니다.
- HWAX 게이트웨이가 사용자를 대신해 부를 수 있습니다. 그 사람 앞으로 하루짜리 개인 토큰 「HWAX 게이트웨이(…)」 가 발급되며, 읽기 · 쓰기 범위만 있고 관리 범위는 없습니다. 같은 창구의 직전 토큰은 회수되고, 포털이 연결 점검과 회수도 합니다.
- 게이트웨이를 거친 요청은 감사 기록 · 접근 로그에 따로 표시됩니다.
- 관리 › 서버 화면에 포털 로그인 · 게이트웨이 위임이 켜졌는지 보입니다.

■ 확인해 주십시오
- 운영자: 포털에 붙일 설치는 update 때 포털 설정(`PORTAL_*`)과 게이트웨이 허용 주소(`HEAX_SSO_ALLOWED_IPS`)를 주십시오. 준 값만 설정에 적힙니다. 자세한 것은 운영 안내서 9절을 보십시오.
- 포털에 붙이지 않는 설치는 그대로입니다(포털 로그인 · 게이트웨이 위임 모두 꺼짐).
