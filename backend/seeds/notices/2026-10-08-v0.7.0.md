# v0.7.0 업데이트 — CalculiX 가 기본 솔버가 되고, CompCore 시험 규격 20개를 모두 풉니다

■ 새로 생긴 것
- CompCore 시험 규격 20개를 CalculiX 로 모두 풉니다(전에는 4개).
- CalculiX 로 가속도 · 중력(관성 하중), 모멘트, 변형체 면의 원격 변위(회전 포함), 여러 강체 파트에 걸친 그룹을 풉니다. 변위로 당기는 시험도 마찰 접촉을 씁니다.
- CalculiX 에서 「큰 변형」 을 켤 수 있습니다.

■ 바뀐 것
- 새 작업의 솔버 기본값이 CalculiX 입니다. 솔버가 적히지 않은 옛 작업은 그대로 Ansys 로 읽으므로, 재시도 · 메시 수렴 점검이 다른 솔버로 돌지 않습니다.
- CalculiX 가 걸 수 없는 조건은 DOE 점마다 해석 중에 멈추지 않고 작업을 만들 때 막습니다.
- 변위로만 당기는 시험을 「하중이 없다」 로 막던 것을 고쳤습니다(두 솔버).
- Ansys 반력을 그 영역의 메시 절점에서 모아 냅니다. 전에는 첫 면의 평면 위 절점만 더해 크게 모자랐습니다(한 시험에서 26,959 N → 57,054 N, CalculiX 57,037 N).
- Ansys: 강체 파트 둘을 한 원격점이나 접촉에 묶으면 입력 파일이 끊기던 것을 고쳤습니다.
- CalculiX: 원격점을 CAD 가 잰 면적 중심에 둡니다. 관성 하중이 있을 때 반력이 작게 나오던 것도 고쳤습니다.
- CalculiX: 강제 변위를 CAD 가 선언한 단위계로 읽습니다. 전에는 SI 단위 폴더에서 1000배 덜 당겼습니다.

■ 확인해 주십시오
- 이전 판의 Ansys 반력, CalculiX 의 원격점 · 관성 하중 반력, SI 단위 폴더의 CalculiX 강제 변위 작업은 다시 돌리십시오.
- CalculiX: 강체에 닿는 마찰 접촉은 아직 붙여서 풀고, 이때 「큰 변형」 을 켜면 막습니다. 선응력 모달에서 앞 정적이 걸 수 없는 하중도 막습니다.
