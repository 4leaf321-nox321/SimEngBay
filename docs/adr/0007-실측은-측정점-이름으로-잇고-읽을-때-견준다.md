# 0007. 실측은 측정점 이름으로 잇고, 읽을 때 견준다

- 상태: 채택
- 날짜: 2026-10-03

## 결정

실측(공진 · FRF · 변위 · 변형률)은 **이 플랫폼의 표 한 장**으로 받는다 — 열은 측정점 · 종류 · 주파수
· 값 · 단위 · 성분(한글 · 영어 이름 둘 다). 장비 고유의 열 이름을 가정하지 않는다. 해석과 잇는 열쇠는
**측정점 이름**(CAD 점 그룹 = 센서 자리)이다.

실측은 `simulation_measurements` 에 **기준 단위로 옮긴 줄들**(mm · mm/s · mm/s² · 무차원)로 두고,
작업 하나 또는 스터디 하나에 붙인다. **견준 값은 저장하지 않는다** — 읽을 때마다 그 결과와 견준다
(`app/core/measured.py`).

## 배경

실측 장비는 아직 정해지지 않았다(2026-10-03). 형식 하나만 받으면 나머지는 나중에 계약을 다시 짜야
하므로 셋 다 받기로 했다(사용자 결정).

## 대안

- **첨부(`files`)로 둔다** — 라우트 · 권한이 이미 있지만 내용이 파일뿐이라 매번 파싱해야 하고, 보이는
  범위가 작업과 다르다(첨부는 내 부서만, 작업은 열린 부서까지).
- **산출물로 둔다** — 재시도가 입력 아닌 산출물 행을 지운다.
- **견준 값을 저장한다** — 결과가 다시 돌면(재시도 · 수렴 점검) 옛 결과와 견준 수가 남는다. 두 벌이
  되면 언젠가 갈리고 갈린 쪽을 화면이 그린다(`result.json` 이 정본이라는 규칙과 같은 까닭).

## 결과

- **짝을 억지로 짓지 않는다.** 실측 공진에는 형상(지문)이 없어 MAC 으로 못 잇는다. 그래서 센서 자리에서
  5% 미만으로 움직이는 모드는 후보에서 빼고(모달 측정점을 **탄성 모드 전부**에서 읽게 바꾼 까닭),
  가까운 주파수를 한 모드에 한 번만 짓고, ±25% 밖은 짓지 않고, 10% 안에 후보가 둘이면 「불확실」 을 적는다.
- **차이를 변수로 설명한다.** 모든 짝이 같은 비율로 어긋나면 영률(f ∝ √E), 봉우리 높이는 감쇠(≈ 1/2ζ —
  실측 곡선의 반전력 대역으로도 잰다), 힘으로 건 정적이면 영률(u ∝ 1/E). 비율이 제각각이면 물성 하나로
  설명되지 않는다고 적는다. **변위로 당긴 모델**(전단 이음)은 영률로 설명하지 않는다.
- 스터디에 붙이면 설계점마다 견주어 **실측에 가장 가까운 점**을 고른다 — 물성 · 감쇠를 훑은 DOE 라면
  그것이 차이를 설명하는 값이다.
- 변형률을 견주려고 정적 결과의 측정점에 **수직 변형률 셋**을 싣는다. 전단 성분은 싣지 않는다 — 솔버마다
  공학 · 텐서 전단의 약속이 달라 같은 칸에 다른 뜻이 들어간다. 게이지 방향은 x · y · z 만 받는다.
- FRF 가 가진력으로 나눈 것(`/N`)이면 봉우리 **위치만** 견준다.
