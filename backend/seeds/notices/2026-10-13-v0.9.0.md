# v0.9.0 업데이트 — Standard Platform 의 기준정보를 받는 「온톨로지」 화면이 생겼습니다

■ 새로 생긴 것
- 「온톨로지」 화면에서 Standard Platform 이 공개한 타입 · 객체 · 관계를 읽기 전용으로 봅니다. 수신 상태 · 타입 · 객체 찾기 · 칸과 관계 · 수신 기록을 봅니다.
- 서버가 기준정보를 주기적으로 받습니다. 바뀐 것만 받고, 지워지거나 합쳐진 객체는 지우지 않고 끄며, 주 1회 전량을 대조합니다. 한 타입이 막혀도 나머지 타입은 받습니다.
- 시스템 관리자는 「지금 받기」 · 「처음부터 전량 받기」 로 바로 받고, 타입마다 받을지 켜고 끕니다.

■ 바뀐 것
- Ansys 가 원격 변위 · 강체 구속의 반력을 구속이 여럿일 때도 냅니다. 전에는 시험 지그의 핀 · 롤러 · 누름쇠 · 비틀림 끝면 반력이 비어 나왔습니다.
- 요소 크기가 스펙에도 CAD 「전체」 메시 힌트에도 없는 CalculiX 작업은 API 로 걸어도 만들 때 막습니다. DOE 가져오기는 그 점을 까닭과 함께 건너뜁니다.

■ 확인해 주십시오
- 운영자: 온톨로지를 받으려면 수신원 주소와 토큰(`ONTOLOGY_SOURCE_URL` · `ONTOLOGY_SOURCE_TOKEN`, core:read 범위)을 설정하십시오. 설정하지 않으면 아무것도 받지 않습니다. 받는 주기는 기본 하루, 전량 대조는 기본 7일입니다.
