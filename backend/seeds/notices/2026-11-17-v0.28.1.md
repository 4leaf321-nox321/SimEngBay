# v0.28.1 업데이트 — 모달은 찾을 주파수 범위를, 조화 응답은 주파수별 가진 프로파일을 받습니다

■ 새로 생긴 것
- 모달 해석에 「찾을 주파수 범위」 가 생겼습니다. 범위 안에서 모드 수만큼 찾고 탄성 모드 차수는 범위 안에서 1부터 세며, CalculiX 는 범위 안 모드가 모자라면 모드 수를 늘려 다시 풉니다(최대 200개 · 4번).
- CAD 조건이 모달 범위를 적었으면 그 값을 먼저 쓰고, 새 해석 작업 창의 범위 칸은 잠근 채 알립니다. 모달 결과 · 한눈 요약에 범위 · 출처 · 범위 아래 탄성 모드 수가 나오고, 범위 안 모드가 모자라면 알립니다.
- 조화 응답 하중에 주파수별 배율 표(선형 보간)와 위상(도)을 겁니다(CompCore v0.28.0 의 가진 프로파일).
- 기저 가진(고정 지지 + 가속도)이면 측정점의 절대 가속도와 위상을 냅니다. 조화 결과 화면에 변위 / 가속도(g) / 위상(°) 보기가 생기고, 측정점 봉우리에 가속도 봉우리와 위상이 붙습니다.

■ 바뀐 것
- CalculiX 모달의 고유치를 한 스레드로 풉니다. 같은 모달을 여러 스레드로 풀면 가끔 틀린 고유치가 나오던 것을 막으며, 속도는 같습니다.

■ 확인해 주십시오
- v0.28.0 은 배포 번들이 나오지 않았습니다. 그 내용은 모두 이 판에 들어 있으니 v0.27.0 에서 이 판으로 바로 올리십시오.
- 이전 판에서 푼 CalculiX 모달 결과는 고유치가 틀렸을 수 있습니다. 중요한 결과는 이 판에서 다시 돌려 확인하십시오.
- 틀린 배율 표는 까닭을 달아 막고, 표가 해석 주파수 범위를 덮지 못하면 그 하중을 막습니다.
- Ansys 의 배율 표 · 위상은 아직 실측으로 확인하지 못했습니다. Ansys 의 측정점 가속도는 기저 가진일 때 지지부 기준 상대 가속도입니다(CalculiX 는 절대 가속도).
- CompCore 의 랜덤 진동 조건은 점 파일을 읽지만, 가속도 PSD 하중은 아직 쓰지 않고 알립니다.
