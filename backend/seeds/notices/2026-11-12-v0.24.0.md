# v0.24.0 업데이트 — 고른 계정의 메일 주소를 한 번에 복사합니다

■ 새로 생긴 것
- 계정 화면 · 부서 멤버 화면에 고르기 칸과 「메일 주소 복사 (N명)」 단추가 생겼습니다. 머리 칸으로 모두 고를 수 있습니다.
- 고른 주소를 `; ` 로 이은 한 줄로 복사하므로, Outlook 받는 사람 칸에 붙여 여러 사람에게 메일 한 통을 씁니다. 같은 주소는 한 번만 넣습니다.

■ 확인해 주십시오
- 메일 주소 형식이 아닌 아이디(예: admin)는 빼고, 무엇을 뺐는지 단추 옆에 적습니다.
- http 로 운영하는 서버에서도 복사됩니다. 브라우저가 복사를 막으면 주소를 칸에 띄우니 Ctrl+C 로 가져가십시오.
