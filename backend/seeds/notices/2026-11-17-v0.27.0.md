# v0.27.0 업데이트 — 모달 DOE 에 주파수 요구 탭이 생겼습니다

■ 새로 생긴 것
- 모달 DOE 스터디에 「주파수 요구」 탭이 생겼습니다. 목표 주파수와 회피 대역을 스터디에 저장하면 설계점마다 적합 · 대역 침범 · 목표 이탈 · 부적합 · 판정 보류로 판정합니다.
- 회피 대역은 실제로 들뜨는 모드(가진 방향 유효질량 · 측정점 응답)만 셉니다. 대역이 여럿이면 모드마다 판정하는 대역을 따로 셉니다.
- 탭에서 DOE 에 없는 자리의 보간 추정, 공차 민감도, 주파수 분포도, 설계 공간 판정도, 후보 설계점을 봅니다. 저장하기 전에 판정을 미리 볼 수도 있습니다.
- HWAX 챗 · Claude 대화에서 작업 결과 · 스터디 · 주파수 요구 · 수렴 · 실측을 부르면 결과 아래에 웹과 같은 결과 화면이 패널로 뜹니다. 3D 형상과 3D 산점도 · 산점도 행렬 · 평행 좌표 그림은 웹에서 보십시오.

■ 바뀐 것
- 구속이 있어도 0 Hz 모드는 강체 모드로 세고, 움직인 바디와 까닭(묶지 않은 쌍 · 미끄럼 접촉)을 결과 경고로 알립니다.
- 맞닿았는데 접촉을 걸지 않은 바디를 「접촉 미정의: 인접 바디」 경고로 알립니다. 미끄럼 접촉은 조건 처리 알림에 남깁니다.
- 경고 낱말을 CompCore v0.26.0 과 맞췄습니다(인접 바디 · 바디 간섭 · 바디 간 미세 간극).

■ 확인해 주십시오
- 이번 판은 데이터베이스 갱신(주파수 요구 저장)과 MCP 서버 옆에 놓이는 결과 화면 패널 파일이 함께 갑니다. 번들의 설치 절차대로 갱신하십시오.
