# v0.35.0 업데이트 — 작업을 취소하면 STE 잡도 멈추고, STE 동시 제출 한도를 둡니다

■ 새로 생긴 것
- 작업을 취소하면 STE 잡도 낸 사람 명의로 클러스터에서 취소하고, 멈춘 것을 60초까지 확인합니다. 단계 시간 초과나 오류로 끝날 때도 같으며, 취소는 감사에 남습니다.
- 서버 화면 「해석 설정」 에 STE 동시 제출 한도(전체 · 사람마다)가 생겼습니다. 한도가 차면 STE 작업만 기다리고 다른 작업은 먼저 풀며, 대기 화면에 까닭이 나옵니다.
- 이 서버의 CalculiX 와 STE 의 CalculiX 가 같은 빌드인지 견줍니다. 다른 빌드면 풀 곳에서 STE 를 고를 수 없고, 작업 만들기 · DOE 가져오기 · STE 로 다시 풀기가 막힙니다.
- 작업 상세의 STE 잡 줄에 「이 서버가 취소함」 · 「결과 버림」 · 「취소를 청함(멈춘 것은 못 봄)」 이 나오고, 빌드가 다른 잡에는 ⚠ 가 붙습니다.
- 운영자가 같은 덱을 이 서버와 STE 에서 각각 풀어 판정 · 고유진동수 · 결과 값을 견주는 회귀 점검 도구가 생겼습니다.

■ 바뀐 것
- 전에는 취소해도 이 서버의 단계만 멈추고 STE 잡은 클러스터에서 끝까지 돌았습니다. 취소 전에 이미 끝난 잡은 결과를 버립니다.

■ 확인해 주십시오
- STE 동시 제출 한도의 기본은 0(한도 없음)입니다. 필요하면 「해석 설정」 에서 정하십시오.
- 어느 한쪽의 CalculiX 빌드를 알 수 없으면 막지 않습니다.
- STE 연동은 아직 실제 STE 에 붙기 전이라 시험용 STE 로만 확인했습니다.
