# v0.5.1 업데이트 — 운영 서버에서 해석 워커가 뜨지 않던 것을 고쳤습니다

■ 새로 생긴 것
- `setup --yes` 로 묻지 않고 원격에서 설치합니다. 준 설정 값(없으면 기본값)으로 같은 순서를 밟고 무엇을 썼는지 찍습니다. 역할(A · B · 단독)은 기본값이 없어 꼭 주어야 하고, 대기 서버(B)가 A 에서 파일을 받는 단계는 ssh 키로만 됩니다.

■ 바뀐 것
- 운영 설치에서 해석 워커가 10초마다 죽고 다시 뜨던 것을 고쳤습니다. 워커를 멈출 때는 돌던 작업을 마치고 나갑니다.
- install · update 가 워커를 띄운 뒤 떠 있는지 보고, 아니면 경고와 함께 로그 끝부분을 보여 줍니다. 전에는 워커가 죽어 가도 「설치 완료」 로 끝났습니다.

■ 확인해 주십시오
- 이전 판으로 설치한 운영 서버는 이 판으로 올리십시오. 워커가 뜨지 않아 작업이 대기에 머물러 있었을 수 있습니다.
- 운영자: 배포 명령에 설정 값을 줄 때는 `sudo X=… ./deploy.sh` 처럼 sudo 뒤에 적으십시오. `X=… sudo ./deploy.sh` 로 적으면 우분투 기본 sudo 가 값을 조용히 버립니다.
