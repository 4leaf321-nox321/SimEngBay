# v0.14.0 업데이트 — AI 도구로 해석을 거는 MCP 가 생기고, 해석 큐를 사람마다 번갈아 집습니다

■ 새로 생긴 것
- 해석용 MCP: Claude Code · Claude Desktop · HWAX 포털의 Claude 같은 AI 도구가 CAD 폴더의 설계점에 해석을 걸고, 결과를 읽고, 설계점 · 실측과 견주고, 시키면 게시합니다. 사용자의 토큰으로 부르므로 권한은 화면과 같습니다.
- 「내 정보 › AI 도구 연결」 에서 Claude Code · Claude Desktop · Gemini · Codex 를 붙이는 법을 봅니다.
- CompCore 스터디 id(앞 6자리 이상)나 이름으로 CAD 공용 폴더의 스터디를 찾습니다. CompCore 가 보여 주는 경로를 몰라도 되고, 못 찾으면 CompCore 에서 내보내라고 알립니다.
- 대기 중인 작업이 줄의 어디쯤인지 보입니다(화면 · MCP).

■ 바뀐 것
- 해석 큐가 사람마다 번갈아 집습니다. 같은 솔버 안에서 도는 작업이 적은 사람, 오래 못 받은 사람, 먼저 건 작업 순입니다. DOE 수백 점을 먼저 건 사람 뒤에서 한 건이 다 기다리지 않습니다.
- 서버 화면이 CalculiX 워커가 하나뿐이면 알립니다.

■ 확인해 주십시오
- 운영자: 포털이나 사람들의 Claude 에 MCP 를 붙일 설치는 `MCP_HOST=0.0.0.0` 으로 열고 `deploy.sh hwax-request` 로 HWAX 요청서를 만드십시오(운영 안내서 5b · 9절). 요청서에는 작업 취소가 위험 도구로 적힙니다.
- 운영자: 여러 사람이 함께 쓰면 워커 수(`WORKER_COUNT`)를 서버 코어 수에 맞추십시오.
