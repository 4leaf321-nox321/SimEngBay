# v0.30.0 업데이트 — 랜덤 진동에 잔여 벡터를 더하고, 단위 점검 경고가 생겼습니다

■ 새로 생긴 것
- CalculiX 작업에 단위 점검이 생겼습니다. 솔버가 센 질량이 이상하거나 STEP 에서 잰 부피가 CompCore 가 보낸 부피와 1 % 넘게 다르면 작업 상세 맨 위 띠로 경고하고, 요약에 덱에 쓴 탄성계수 · 밀도와 바디를 싣습니다.
- 자유-자유 모달에서 1 Hz 를 넘어도 모양이 강체 운동인 모드는 강체 모드로 세고 경고합니다.

■ 바뀐 것
- 랜덤 진동의 범위는 이제 모드를 찾을 범위입니다(모달과 같은 칸). 가진 대역은 늘 PSD 표 전체이며, v0.29.0 은 그 범위로 PSD 를 잘랐습니다.
- 랜덤 진동에 잔여 벡터를 더해 빠진 모드의 몫을 채웁니다. 모드 수에 따라 +20 % ~ -13 % 출렁이던 준정적 응답이 0.01 % 안으로 맞습니다.
- CalculiX 에서 본딩으로 묶은 조립의 자유-자유 강체 모드가 0 Hz 보다 높게(쉘 ↔ 솔리드 본딩은 12.8 Hz 까지) 나오던 것을 고쳤습니다.
- 온도마다 물성이 다른 재료는 초기조건의 「환경 온도」(없으면 22 °C)를 기준으로 값을 고릅니다. 같은 거리면 낮은 온도를 쓰고, 요약에 쓴 온도를 적습니다.
- CompCore v0.29.0 이 내보낸 폴더(설계점마다 가진 축이 다른 랜덤 진동 스터디 포함)를 받습니다.

■ 확인해 주십시오
- 작업 상세에 단위 경고 띠가 보이면 CompCore 의 단위와 물성을 확인하십시오. 단위가 어긋나면 1차 탄성 주파수가 1000 배로, 질량이 mg 단위로 나올 수 있습니다.
- v0.29.0 으로 저장된 랜덤 진동 결과도 화면에서 열리지만, 잔여 벡터 없이 범위로 자른 PSD 로 센 값입니다. 견줄 때는 이 판에서 다시 돌리십시오.
- 본딩한 조립의 자유-자유 모달은 이 판에서 다시 돌려 강체 모드를 확인하십시오.
