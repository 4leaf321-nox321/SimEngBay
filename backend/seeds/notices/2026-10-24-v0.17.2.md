# v0.17.2 업데이트 — Ansys 비선형 정적의 3D 그림이 수와 같은 단계를 그립니다

■ 새로 생긴 것
- MCP 에서 사람이 나눈 정리 폴더를 나무로 보고 작업을 옮기는 도구가 생겼습니다. CAD 공유 폴더와는 다른 것이라고 안내합니다.

■ 바뀐 것
- Ansys 비선형 정적(큰 변형 · 마찰 · 부단계)의 3D 그림이 첫 부단계를 그려 수보다 훨씬 작은 모양이었습니다(보드굽힘에서 그림 0.30 mm, 수 6.05 mm). 이제 수와 같은 마지막 단계를 그리며, 선형 정적과 CalculiX 는 원래 맞았습니다.
- DOE 화면의 「CSV 내보내기」 가 「표 복사」 로 바뀌었습니다. 사내 DRM 으로 파일을 받지 못해 표를 클립보드에 넣으며, 엑셀에 붙이면 칸이 그대로 섭니다(http 에서도 됩니다).
- MCP 작업 목록이 화면의 「해석」 목록과 같이 단일 해석과 DOE 한 벌을 한 줄씩 냅니다. 상태로 거르면 설계점까지 낱개로 냅니다.
- 「해석」 목록의 「부서」 를 실행한 사람 아래 줄로 옮기고, 「생성」 은 날짜만 적습니다(시각은 마우스를 올리면 보입니다). 노트북 폭에서 오른쪽 열이 잘리던 것을 고쳤습니다.
- 작업 요약의 바디별 질량이 「…」 로 잘리지 않고 줄을 접어 다 보입니다.

■ 확인해 주십시오
- 이미 끝난 Ansys 비선형 정적 작업의 그림은 옛 그대로입니다. 다시 실행하면 마지막 단계로 그립니다.
- 연계 스크립트가 쓰는 CSV 파일 받기는 그대로 남습니다.
