# v0.33.0 업데이트 — CalculiX 를 STE 클러스터에서 풀고, 해석 설정을 서버 화면에서 바꿉니다

■ 새로 생긴 것
- CalculiX 작업을 STE(Slurm 클러스터)에서 풀 수 있습니다. 작업 설정의 `solve_on` 을 `ste` 로 두면 솔브 단계를 STE 잡으로 내고, 판정 · 메모리 재시도 · 모드 찾기는 이 서버에서 풀 때와 같습니다.
- STE 잡은 작업을 건 사람의 명의로만 냅니다. 잡 메모리는 모델 크기로 어림하고(2~64 GB), 메모리가 모자라면 반복 솔버로 다시 내며, 시간 초과는 실패로 둡니다.
- 서버 화면에 「해석 설정」 이 생겼습니다(시스템 관리자). 본딩 방식 · 선형 솔버 · 허용오차 · 점당 스레드 · STE 메모리 상한 같은 값을 재시작 없이 바꾸고, 바꾼 기록은 감사에 남습니다.

■ 바뀐 것
- 결과를 바꾸는 설정은 작업을 만들 때 고정됩니다. 다시 돌리기 · 메시 점검 · 모드 바꿔 다시 돌리기는 원래 값을, DOE 가져오기는 가져올 때 한 번 잰 값을 씁니다.
- `.env` 에 적은 본딩 방식 · CalculiX 실행 파일 같은 값이 실제 해석 단계에 닿지 않던 것을 고쳤습니다. 설정은 서버 화면 → `.env` → 기본값 차례로 정합니다.

■ 확인해 주십시오
- STE 가 설정되지 않은 서버에서는 STE 작업을 만들 때 거절합니다. STE 인증 실패 · 응답 없음 · 거절이면 작업이 실패하며, 이 서버로 몰래 물러서지 않습니다.
- STE 의 제출 · 상태 경로는 아직 실제 STE 에 붙여 확인하기 전입니다. 처음에는 작은 작업으로 먼저 확인하십시오.
- 이전 판에서 `.env` 로 바꾼 본딩 · 솔버 값은 해석에 쓰이지 않았습니다. 그 값을 믿고 돌린 작업은 다시 돌리십시오.
- CalculiX 실행 파일 자리와 STE 비밀은 서버 화면이 아니라 `.env` 에 둡니다. 이번 판은 데이터베이스 갱신(해석 설정 저장)이 함께 갑니다.
