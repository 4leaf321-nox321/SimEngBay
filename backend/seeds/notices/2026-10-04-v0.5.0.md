# v0.5.0 업데이트 — 새 해석 작업을 CAD 공용 폴더에서 고릅니다

■ 새로 생긴 것
- 새 해석 작업 창에서 DOE 가져오기처럼 CAD 공용 폴더를 훑어 설계점 하나를 고릅니다. 서버가 그 점의 조건 파일 · STEP · 중간면을 읽어 같은 미리보기를 보입니다. 파일을 직접 올리는 길은 두 번째 탭으로 남았습니다.
- CompCore 의 「설계 하나」(인자 없는 스터디)를 받습니다. 그 폴더에서 만든 작업은 출처가 「CAD 설계」 이고, 이름은 폴더 이름이 기본입니다.
- 배포가 CAD 공용 폴더 · Ansys 설치 경로 · Ansys 판 · 워커 수를 설치 기록에 남기고 다음 배포 때 다시 읽습니다.
- 배포 상태 보기에 「CAD 공용 폴더」 칸이 생겼고, 처음 설치(setup) 때 CAD 폴더와 Ansys 폴더를 묻습니다.

■ 바뀐 것
- 같은 설계를 두 번 가져오는 것은 DOE 점과 같이 막습니다.
- install · update 끝에 CAD 공용 폴더를 운영 계정으로 읽어 봅니다. 못 읽으면 마운트 설정을 안내합니다.

■ 확인해 주십시오
- 운영자: 이전 판에서는 update 때 CAD 폴더 · Ansys 경로를 빠뜨리면 폴더 연결이 조용히 빠지고 워커가 1개로 줄었습니다. 이 판으로 올린 뒤 상태 보기의 「CAD 공용 폴더」 와 서버 화면의 워커 수가 맞는지 확인하십시오.
