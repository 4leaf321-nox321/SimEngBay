# v0.31.0 업데이트 — Ansys 로도 랜덤 진동을 풀고, 조화 · 랜덤 결과에 응력이 나옵니다

■ 새로 생긴 것
- Ansys 로도 랜덤 진동을 풉니다(Mechanical 의 Random Vibration). CalculiX 셈과 측정점 가속도는 0.12 %, 1σ 변위는 0.43 % 안에서 맞습니다.
- CalculiX 조화 응답 결과에 봉우리 주파수의 최대 상당응력이 나옵니다.
- CalculiX 랜덤 진동 결과에 상당응력 1σ/3σ 가 나옵니다.
- 조화 · 랜덤 응력이 결과 값 · DOE 비교 표 · CSV · 수렴 지표에 들어갑니다.
- Ansys 작업에도 CalculiX 와 같은 단위 점검(덱 물성 · 형상 크기 · 총질량)이 붙습니다.

■ 바뀐 것
- CalculiX 조화 응답에 잔여 벡터를 더합니다. 모드 수가 모자라 응답이 작게 나오던 것(150 Hz 시험 모델에서 모드 20 개일 때 -29.5 %)이 정적 해와 같아집니다.
- Ansys 조화 응답에서 위상을 건 하중이 멈추던 것을 고쳤습니다. 주파수별 배율 표도 실측으로 확인했습니다.
- Ansys 워커가 정적 결과에서 원격 변위의 반력을 읽다가 죽던 것(종료 코드 5)을 고쳤습니다.

■ 확인해 주십시오
- 이전 판에서 모드 수를 적게 두고 푼 CalculiX 조화 응답은 응답이 작게 나왔을 수 있습니다. 이 판에서 다시 돌려 확인하십시오.
- 이전 판에서 위상을 건 Ansys 조화 응답이 멈췄다면 다시 돌리십시오.
