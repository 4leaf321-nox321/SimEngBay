# v0.19.0 업데이트 — DOE 를 지우지 않고 모드 수만 바꿔 다시 겁니다

■ 새로 생긴 것
- DOE 화면에 「모드 수 바꿔 다시 걸기」 단추가 생겼습니다(MCP 도구도 있습니다). 점마다 마지막 작업의 입력을 그대로 써서 모드 수만 바꾼 새 작업을 만들고, 옛 작업은 기록으로 남깁니다.
- CalculiX 결과에도 모드 성격(변위 축 비중 · 전역/국부)이 나옵니다.
- 바디가 둘 이상이면 모드마다 어느 파트가 움직이는지 먼저 말하고, 국부성은 그 파트 안에서 잽니다. 결과 화면의 「성격」 칸과 뷰어에 「기둥 100% · 전역 0.43」 처럼 나옵니다.

■ 바뀐 것
- 모드 성격을 절점 수 대신 절점이 맡은 부피(쉘은 넓이 x 두께)로 가중해 「움직이는 부피의 몫」 으로 셈합니다. 두 솔버가 같은 셈을 써서 같은 값을 냅니다.
- 모드를 못 이은 자리(—)의 안내가 새 다시 걸기 단추를 가리키고, 작업 화면의 경로가 「모드 6 → 10개로 다시 걸음」 처럼 적습니다.
- 재료처럼 고르는 변수가 섞인 여러 변수 DOE 도 단면(예: 「두께 = 6」)으로 묶어 그립니다. 고정을 풀면 겹치는 막대에 설계점을 붙입니다(예: 「SS400 · p0003」).

■ 확인해 주십시오
- 다시 걸기는 내가 건 점만 다시 걸고, 도는 점이 있으면 걸지 않으며, 입력이 정리된 점은 까닭과 함께 건너뜁니다. 정리 폴더는 따라가지만 게시는 옮기지 않으니 필요하면 다시 게시하십시오.
- 부피 가중 · 파트별 모드 성격은 이번 판 이후로 푼(또는 다시 건) 작업부터 붙습니다.
