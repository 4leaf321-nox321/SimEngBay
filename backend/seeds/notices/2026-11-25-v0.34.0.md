# v0.34.0 업데이트 — 새 작업 · DOE 가져오기에서 풀 곳(이 서버 / STE 클러스터)을 고릅니다

■ 새로 생긴 것
- 새 작업 · DOE 가져오기 창에 「풀 곳」 이 생겼습니다. 이 서버와 STE 클러스터 중에서 고르며, DOE 는 가져오기 한 번에 고른 풀 곳 하나를 모든 점에 씁니다.
- 풀 곳 칸은 내 명의로 STE 를 물어, 고를 수 있으면 남은 코어 · 대기 잡 · 내 대기/실행 잡을, 못 고르면 까닭(설정 없음 · STE 가 거절 · 응답 없음)을 보여 줍니다.
- STE 가 안 돼 실패한 작업은 상세에 「이 서버에서 다시 풀기」 가 나옵니다. 다시 걸 때 풀 곳을 바꾸면 바꾼 기록이 남습니다.
- 작업 목록 · 스터디 점 표 · 상세 머리에 「STE 클러스터」 표시가, 솔브 단계 옆에 STE 잡(번호 · 상태 · 대기 · 실행 · 메모리)이 나옵니다.
- MCP 의 작업 만들기 · 다시 돌리기에서도 풀 곳을 고릅니다.

■ 확인해 주십시오
- STE 는 CalculiX 만 풉니다. 솔버를 Ansys 로 바꾸면 풀 곳이 이 서버로 돌아가고, Ansys 작업은 STE 로 옮겨 다시 걸 수 없습니다.
- 서버는 풀 곳을 몰래 바꾸지 않습니다. STE 로 실패한 작업은 직접 「이 서버에서 다시 풀기」 를 누르십시오.
- STE 대기열 요약의 항목은 아직 실제 STE 응답에 맞춰 확인하기 전입니다.
