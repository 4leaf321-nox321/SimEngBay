# v0.36.0 업데이트 — 솔버 능력표를 열고, 조화 응답이 풀지 못하는 조건은 만들 때 막습니다

■ 새로 생긴 것
- 솔버마다 받는 해석 · 구속 · 하중 · 접촉 · 초기조건 · 재료를 알리는 능력표를 API · MCP 로 엽니다. CompCore 가 케이스의 대상 솔버에 맞춰 저장 · 내보내기 때 조건을 거르는 데 씁니다.
- 능력표는 손으로 적지 않고 실제로 받는 규칙에서 만들어, 표와 실제 동작이 어긋나지 않습니다. 읽기 범위의 개인 토큰(PAT)으로도 읽힙니다.

■ 바뀐 것
- 조화 응답에 실린 선응력을 작업 만들 때 까닭과 함께 막습니다(모달로 적은 점을 조화로 돌려도 같습니다). 전에는 두 솔버 모두 말없이 무시했습니다.
- 조화 응답에서 볼트 예압 · 회전 속도 · 중력을 두 솔버 모두 작업 만들 때 막습니다. 1 g 로 흔들려면 가속도 하중으로 적으십시오. 가속도 · 압력 · 힘 · 모멘트 · 베어링 하중은 그대로 풉니다.
- Ansys 가 해석 종류부터 걸 수 없는 조건(랜덤 진동의 선응력)도 작업 만들 때 막습니다.
- 조화 응답이 아닌 해석에서는 배율 표를 검사하지 않고, 예압은 볼트에서만 읽습니다.

■ 확인해 주십시오
- 이전 판에서 조화 응답에 선응력을 건 작업은 선응력 없이 풀렸고, CalculiX 에서 중력을 건 조화 응답은 중력을 1 g 가진으로 흔들어 풀었습니다. **조건을 고쳐 다시 돌리십시오.**
