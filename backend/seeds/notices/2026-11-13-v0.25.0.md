# v0.25.0 업데이트 — CalculiX 경로의 메시 문제 넷을 고쳤습니다

■ 새로 생긴 것
- 결과 요약에 「형상 맞춤 허용오차」 · 「메시 보정」 · 「선형 솔버」 · 「메모리 어림」 · 「메모리 경고」 · 「다시 푼 까닭」 이 나옵니다.
- CompCore 가 바디 사이 접촉을 점검해 보냈으면, 겹침 · 틈을 붙였는지 남겼는지 「메시 보정」 에 적습니다.

■ 바뀐 것
- 바디 사이의 아주 작은 겹침 · 틈을 형상 맞춤 허용오차 안에서 맞닿은 것으로 붙입니다. 전에는 0.01 mm 겹침이 얇은 조각을, 0.005 mm 틈이 떠 있는 바디를 만들었습니다.
- 바디별 요소 크기를 메시를 쪼갠 뒤 원래 바디에 맞춰 줍니다. 전에는 겹친 곳이 있으면 한 바디의 크기가 겹친 조각에 붙어 바디마다 준 크기가 서지 않았습니다.
- 메시가 서지 않으면 곡률에 맞춘 크기로 다시 만들고 그렇다고 적습니다. 2차 요소가 뒤집혀 CalculiX 가 멈추던 것을 메시 최적화와 중간 절점 바로잡기로 막습니다.
- 정적에서 직접 솔버의 메모리가 남은 메모리의 70 % 를 넘을 것 같으면 반복 솔버로 풉니다. 메모리 때문에 끊기면 반복 솔버로 한 번 더 풀고, 그마저 못 쓰면 실패 글에 메모리 어림을 적습니다.

■ 확인해 주십시오
- 강체 묶음 · 볼트 예압 · 원통 지지처럼 구속식이 드는 해석과 접촉 · 모달 · 조화는 반복 솔버를 쓰지 않습니다(반력이 틀리게 나옵니다). 메모리가 넘칠 것 같으면 「메모리 경고」 로 알립니다.
- 허용오차는 모델 크기(바디 상자 대각선의 1만분의 1)로 정합니다.
- 바디마다 요소 차수를 달리 줘도 아직 전체 차수 하나로 풀고 그렇다고 적습니다.
