# v0.29.0 업데이트 — 랜덤 진동(가속도 PSD) 해석을 CalculiX 로 풉니다

■ 새로 생긴 것
- 랜덤 진동 해석이 생겼습니다. CompCore 의 랜덤 진동 조건(지지부 전체에 거는 가속도 PSD, g²/Hz)을 받아 모달 해석을 한 번 풀고 모드 중첩으로 응답을 셉니다.
- 새 작업 창에 「랜덤 진동」(셈할 범위 · 감쇠비 · 모드 수)이 생겼습니다. CAD 조건이 랜덤 진동이면 저절로 고르고 솔버를 CalculiX 로 맞춥니다.
- 셈할 범위는 CAD 조건 → 작업 설정 → PSD 표 차례로 정하고 늘 PSD 표 안으로 자릅니다. 감쇠비는 CAD 조건이 먼저입니다.
- 결과 화면에 입력 Grms, 측정점 가속도 1σ/3σ(절대), 최대 1σ 변위/3σ(지지부 기준), 로그-로그 PSD 그림, 모드별 유효질량 몫, 1σ 변위 3D 가 나옵니다.
- DOE 비교 표 · CSV · 수렴 지표와 MCP 스터디 분석에 랜덤 진동 값이 들어갑니다.

■ 확인해 주십시오
- 랜덤 진동은 CalculiX 로만 풉니다. Ansys 로 걸면 까닭을 달아 거절합니다.
- PSD 표는 두 줄 이상이어야 하고, 주파수는 커지는 차례, 값은 0 보다 커야 합니다(표 사이는 로그-로그 보간).
- 가장 높은 모드가 범위 상한의 1.5 배에 못 미치면 경고합니다. 경고가 뜨면 모드 수를 늘려 다시 돌리십시오.
