# 0005. StandardPlatform 을 포크하되 온톨로지 · MCP · 파이프라인은 가져오지 않는다

- 상태: 채택
- 날짜: 2026-09-20

## 결정

SimEngBay 는 StandardPlatform(v0.4.8 시점)을 **포크한 별도 저장소**다. 가져온 것은
로그인 · 계정 · PAT · 부서 · 권한 · 공지 · 알림 · 감사 · 첨부 · 서버 상태 · 확장 모듈 기제 ·
Apptainer 배포(이중화 포함)다.

가져오지 않은 것: 온톨로지 · 객체 · 지식 그래프 · RDF · 검색 · 데이터 소스 · 웹훅 · MCP 서버 ·
정제 파이프라인, 그리고 그것들의 마이그레이션 23개. 마이그레이션은 모델에서 다시 만든
`0001_initial` 하나로 시작한다.

## 배경

StandardPlatform 은 두 방식으로 쓰게 되어 있다 — (가) 같은 코드로 인스턴스 여럿, (나) 포크해
다른 제품군으로. 이 플랫폼은 (나)다. 이유:

- 도메인이 「해석 작업(job)」 이고, 그 핵심은 PyMechanical · DPF 위의 **파이프라인**이다.
  「타입을 정의하면 화면이 생기는」 온톨로지 모델과 맞지 않는다 — 작업은 상태 기계이고 산출물은
  파일(`.mechdb` · `.dat` · `.rst` · VTP)이다.
- Ansys 의존성은 이미지 성격이 다르다(호스트의 `/ansys_inc` 를 bind). 틀의 이미지에 얹으면 그 틀을
  쓰는 모든 인스턴스가 그것을 든다.
- 온톨로지 · MCP · 파이프라인은 틀 코드의 절반이 넘는다. 안 쓰는 채로 들고 가면 시험 · 마이그레이션 ·
  문서가 전부 그것을 따라오고, 고칠 때마다 「이건 우리 것인가」 를 물어야 한다.

## 대안

1. **StandardPlatform 확장 모듈로 구현** — 로그인 · 배포를 공짜로 얻지만 온톨로지 표가 DB 에
   생기고 틀이 커질 때마다 함께 무거워진다. 기각.
2. **온톨로지 이전 커밋(`1323c43`, 2026-09-11)에서 포크** — 깨끗하지만 그 뒤 8일 동안 틀에 들어온
   PAT · 이중화 · 접두어 미들웨어 · `.env` 이름 · 설치 마법사를 못 받는다. 기각.
3. **최신에서 포크하고 걷어내기(채택)** — 걷어낼 자리가 `main.py` · `all_models.py` · 사이드바 ·
   라우터 · 부서 홈 · 시험 몇 개로 한정되어 있었다(틀이 조립 지점을 하나로 둔 덕이다). 반나절.

AutoJigGenerator 는 같은 물음에 「구조만 가져와 새로 세운다」 를 택했다(그쪽 ADR 0001). 그때는
틀에 PAT · 이중화가 없어 갈라져도 잃는 것이 적었다. 지금은 그 둘이 이 플랫폼에 필요하다 —
오케스트레이터가 PAT 로 붙고, 해석 서버는 이중화가 요구될 수 있다.

## 결과

- 백엔드 모듈은 `accounts · audit · auth · files · notices · notifications · server · workspaces`
  여덟. 시험 106개, 프론트 시험 54개.
- 걷어낸 것과 함께 지운 것: `shared/system_sources.py` · `shared/sheets.py` · `shared/singleton.py`,
  `scripts/promote_type.py` · `sync_datasources.py`, `deploy/mcp.service.template` · `sync.*.template` ·
  `build_pipeline_kit.sh`, 헤더의 전체 검색 칸, 부서 홈의 위젯, 내 정보의 「AI 도구 연결」(→ API 호출 예).
- `deploy.sh` · `ha.sh` 의 MCP · 동기화 분기는 **남겨 두었다** — 번들에 파일이 없으면 건너뛰고,
  나중에 해석용 MCP 서버를 둘 때 그 자리를 그대로 쓴다. nginx 조각의 `/<slug>/mcp` upstream 은 아무도
  안 듣는 포트를 가리키므로 그 경로만 502 가 난다 — MCP 를 두기 전까지는 무해하다.
- 틀의 개선을 자동으로 못 받는다. 인증 · 배포는 이미 안정된 부분이라 갈라져도 비용이 작다.
  필요한 것은 골라서 옮긴다.
