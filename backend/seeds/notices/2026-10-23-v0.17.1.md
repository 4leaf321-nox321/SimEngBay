# v0.17.1 업데이트 — 시험 지그에 재료가 붙어 오는 CompCore 시험 규격을 확인했습니다

■ 바뀐 것
- CompCore 가 시험 규격의 강체 지그(롤러 · 노즈 · 핀)에 기본 강재 「일반 구조용 강(지그 기본)」 을 붙여 내보냅니다. 보드굽힘 · 숏빔전단 · 핀베어링 셋을 CalculiX 로 다시 풀어 결과가 같음을 확인했습니다(지그는 강체라 재료가 답을 바꾸지 않습니다).
- CompCore 의 절점 상한(기본 10만) 때문에 보드굽힘의 전역 요소 크기 제안이 0.6 mm 에서 2 mm 로 커졌습니다.

■ 확인해 주십시오
- 서버 동작은 바뀌지 않았습니다. 갱신하지 않아도 됩니다.
