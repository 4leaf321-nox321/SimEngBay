# v0.12.0 업데이트 — 해석 작업은 건 사람의 것이 되고, 게시해야 다른 사람이 봅니다

■ 새로 생긴 것
- 끝난 해석 작업 · DOE 를 게시하거나 게시를 풉니다. 게시한 작업은 누구나 읽을 수 있고(바꾸지는 못합니다), 메시 수렴 수준도 함께 게시됩니다. 게시와 해제는 감사 기록에 남습니다.
- 해석 화면에 두 번째 사이드바가 생겼습니다. 「개인 작업」 · 「공용 작업공간」(시스템 관리자는 「전체」)마다 해석 작업 · DOE 비교를 봅니다.
- 작업 화면 「파일」 탭의 「전체 다운로드」 로 산출물 전부를 ZIP 하나로 받습니다. 없는 파일은 묶음 안의 「빠진_파일.txt」 에 적힙니다.
- DOE 상세가 비교 · 설계점 · 검증 탭으로 나뉩니다. 설계점 탭에서 점마다 상태와 오류를 봅니다.

■ 바뀐 것
- 해석 작업은 건 사람과 시스템 관리자만 봅니다. 전에는 부서 단위로 열려 실패한 작업이나 메시만 바꿔 본 작업까지 모두에게 보였습니다.
- 재시도 · 취소 · 정리 · 실측 넣기 · 메시 수렴 점검은 건 사람이나 시스템 관리자만 합니다.
- DOE 가져오기가 다른 사람의 게시 전 작업과 겹치면 누구 작업인지 알리고 막습니다. 같은 해석을 두 번 돌리지 않기 위해서입니다.
- 해석 종류 목록에서 조화 응답이 빠지던 것을 고쳤습니다.

■ 확인해 주십시오
- 이 판으로 올리기 전에 끝난 작업은 모두 게시된 것으로 옮겨집니다. 다른 사람에게 보이지 않아야 할 작업은 게시를 푸십시오.
