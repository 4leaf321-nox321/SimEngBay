# v0.21.0 업데이트 — 정적 결과에 볼트 힘이 나오고, 바디에 건 볼트 예압을 받습니다

■ 새로 생긴 것
- 정적 결과에 볼트마다 조인 힘 · 끝의 힘 · 조임량이 실립니다(CalculiX · Ansys). 정적 결과 화면의 볼트 표, DOE 비교 표의 「볼트 <이름> 힘 (N)」 열, DOE 분석(MCP 포함)에서 끝의 힘을 봅니다.
- 바디에 건 볼트 예압을 받습니다(CalculiX · Ansys). 하중의 좌표계가 단면을 정하며(Z 축 = 볼트 축, 원점 = 단면 자리), 원통면에 건 예압과 같은 볼트 힘이 나옵니다.
- 초기조건 「선응력」 을 받습니다. 전에는 선응력 모달 폴더가 「아직 걸 수 없다」 로 통째로 멈췄습니다.

■ 바뀐 것
- 바디 그룹을 구속 · 접촉 · 면 하중에 걸면 면이 아닌 「바디(body)」 라고 알립니다. 바디 그룹은 볼트 예압만 받습니다.

■ 확인해 주십시오
- 바디에 건 볼트 예압에는 좌표계가 꼭 있어야 하며, 전역 좌표계면 막습니다.
- 초기조건 가운데 다른 해석의 단계에서 가져오는 것은 까닭을 달아 아직 막습니다.
- CalculiX 는 판 사이 마찰이 있는 볼트 조립을 아직 실용 시간에 풀지 못합니다. 본딩만 있는 판끼리 볼트는 두 솔버의 끝 볼트 힘이 0.01 % 안에서 맞습니다.
