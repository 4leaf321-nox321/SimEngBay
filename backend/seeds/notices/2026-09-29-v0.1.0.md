# v0.1.0 업데이트 — CompCore DOE 를 받아 Ansys 로 모달 해석을 풀고 설계점을 견줍니다

■ 새로 생긴 것
- SimEngBay 첫 판입니다. CompCore 가 내보낸 형상과 CAD 조건으로 Ansys 모달(고유진동수) 해석을 돌립니다. 결과는 CompCore 로 돌려보내지 않으므로 설계점은 이 플랫폼에서 보고 고릅니다.
- 로그인 · 계정 · 개인 접근 토큰 · 부서 · 권한 · 공지 · 알림 · 감사 기록 · 첨부 · 서버 상태 화면을 함께 갖췄습니다.
- 「해석 작업」 화면에서 작업 목록과 단계(형상 받기 · 모델링 · 솔브 · 결과 추출)마다의 진행을 봅니다. 실패하면 까닭이 적히고 다시 돌릴 수 있습니다. 진행 중인 작업은 취소할 수 있으며, 취소는 실패로 세지 않습니다.
- 결과 화면에 고유진동수 표, 스펙트럼 · 누적 유효질량 · 모드별 그림, 모드 썸네일, 3D 뷰어가 있습니다. 바디 부피와 밀도로 낸 질량도 함께 보여 줍니다.
- CompCore 가 보낸 영역 지문(면의 위치 · 넓이 · 반지름)으로 형상에서 면을 다시 찾아 고정 지지를 겁니다. 두께를 바꾼 설계점에서도 같은 면을 찾고, CAD 가 못 푼 영역 이름도 보여 줍니다.
- 「DOE 가져오기」 는 공용 폴더 탐색기에서 CompCore DOE 폴더를 골라 먼저 훑어 본 뒤 겁니다. 못 쓰는 점은 이유와 함께 목록에 남고, 같은 폴더를 다시 가져와도 작업이 두 벌 생기지 않습니다.
- 「DOE 비교」 는 스터디 하나를 한 장에 보여 줍니다. 한 줄 요약 · 모드 지도 · 질량 대 주파수 트레이드오프(고를 만한 점에 「후보」 표시) · 모드 x 설계점 행렬이 있습니다.
- 설계점 사이의 모드는 순번이 아니라 모드 형상으로 잇습니다. 그래서 순서가 바뀐 모드도 바르게 이어지고, 못 이은 자리는 비워 둡니다. 재료처럼 숫자가 아닌 변수는 막대로 그립니다.
- CAD 가 보낸 물성으로 풉니다(DOE 가져오기 창의 「CAD 가 보낸 물성 쓰기」). 파트마다 재료가 다르면 바디마다 붙이고, 어떤 탄성계수 · 밀도로 풀었는지 모델링 요약에 적습니다. 재료나 물성 배율을 훑은 DOE 도 받습니다.
- CAD 가 선언한 단위계(mm · N · tonne 등)에 맞춰 해석을 세웁니다. 모르는 단위계를 선언한 점은 걸지 않고 미리보기에서 이유를 알립니다.
- 끝난 작업의 중간 파일을 지우는 「작업 정리」 가 있습니다(결과는 그대로 남습니다). 정리한 작업에서는 모드를 더 뽑을 수 없어 자동으로 돌지 않고, 사람이 누를 때만 돕니다. 서버 화면에 작업 폴더 크기가 뜹니다.

■ 확인해 주십시오
- 설치할 때는 번들을 서버로 옮긴 직후 체크섬을 맞추고, 처음 한 번 `deploy.sh prepare` 뒤 `deploy.sh install` 로 설치하십시오. 절차의 정본은 번들 안 README 입니다.
- DOE 가져오기는 설치할 때 걸어 준 공용 폴더만 읽기 전용으로 봅니다. 공용 폴더 자리(`DOE_ROOT_HOST_DIR`)를 주지 않으면 「공용 폴더가 설정돼 있지 않습니다」 가 뜨고 단건 업로드만 됩니다.
- 워커 수는 Mechanical 라이선스 수에 맞추십시오. 리눅스 서버에서 Ansys 로 도는 길은 아직 실제로 확인하지 못했으니, 설치 뒤 첫 작업이 모델링 단계를 넘는지 보십시오.
- 이 판이 해석에 쓰는 CAD 조건은 영역(고정 지지) · 단위계 · 물성뿐입니다. 다른 구속 · 하중 · 접촉은 폴더에 실려 와도 아직 쓰지 않으며, 엣지 · 점 선택 그룹은 면 그룹만 걸 수 있다고 알립니다.
- 탄성계수가 비어 있는 물성이나 부피 · 무게중심으로 어느 바디인지 가리지 못하는 파트는 다른 값으로 풀지 않고 실패합니다. 탄성계수가 있는 재료로 다시 내보내거나 「CAD 가 보낸 물성 쓰기」 를 끄고 화면 값으로 돌리십시오.
- CompCore 에서 예전에 화면으로 만든 DOE 폴더에는 물성 · 구속이 빠져 있어 화면에서 준 값으로 풀립니다.
