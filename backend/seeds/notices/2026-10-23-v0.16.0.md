# v0.16.0 업데이트 — DOE 「다변수」 탭이 생기고 해석 작업 · DOE 를 지울 수 있습니다

■ 새로 생긴 것
- DOE 상세에 「다변수」 탭이 생겼습니다. 3D 산점도 · 2변수 영향(전 조합이면 등고선, 아니면 색 산점도) · 주효과 · 산점도 행렬 · 평행 좌표 · 상관을 한 화면에서 봅니다.
- 해석 작업과 DOE 를 지울 수 있고, DOE 화면의 「모두 멈추기」 로 DOE 를 통째로 멈춥니다. 지우면 목록에서 사라지고 작업 폴더 · 메시 수렴 수준 · 실측 · 설계점의 앞선 시도도 함께 지워집니다.
- 새 작업 창이 CompCore 가 제안한 전역 요소 크기와 그 까닭을 보입니다. 전역 크기는 스펙 → CAD 「전체」 → CompCore 제안 순서로 정하고, 파트 · 면 · 엣지 크기는 그대로입니다.
- MCP 로 CompCore 스터디 id 나 Windows 경로를 그대로 주어 작업을 겁니다. DOE 분석(민감도 · 주효과 · 결과마다 최소 · 최대 점 · 조건을 건 최적점)을 서버가 셈하고, DOE 멈추기 · 서버 상태 · 중간 파일 정리 도구도 생겼습니다.

■ 바뀐 것
- 작업을 취소하거나 시간 초과로 멈추면 그 아래 메시 · 솔버 프로세스까지 함께 내립니다. 전에는 멈춘 CalculiX 가 남아 서버 메모리가 바닥났습니다.
- 워커 전체가 서버의 정해진 CPU · 메모리 몫 안에서 돕니다. 메모리가 넘치면 가장 큰 해석 하나만 「메모리 부족」 으로 끊기고 서버는 살아 있습니다.
- 정적 결과의 3D 그림이 빈 상자로 나오던 것을 고쳤습니다. 정적은 최대 변형 모양으로 서고 재생 단추가 없습니다.
- 작은 부품의 질량이 0 으로 나오던 것을 고쳤습니다. 결과 숫자를 유효숫자 6자리로 남기고, 화면은 질량을 크기에 맞는 단위(kg · g · mg)로 적습니다.

■ 확인해 주십시오
- 지우기 · 모두 멈추기는 건 사람이나 시스템 관리자만 할 수 있고, 도는 작업은 지우지 않습니다. 지운 설계점은 다시 가져올 수 있습니다.
- 이번 갱신이 워커 묶음(CPU · 메모리 몫)을 만들고 워커를 다시 띄웁니다. 워커 수가 서버에 비해 많으면 갱신 때 권장 수를 알려 줍니다.
- 운영자는 HWAX 포털 담당에게 위험 도구 둘(`study_cancel` · `files_tidy`)을 더 막아 달라고 요청하십시오.
- 질량이 0 으로 저장된 옛 작업은 「—」 로 보입니다. 다시 실행하면 질량이 나옵니다.
