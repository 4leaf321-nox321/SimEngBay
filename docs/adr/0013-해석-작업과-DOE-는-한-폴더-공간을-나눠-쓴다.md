# 0013. 해석 작업과 DOE 는 한 폴더 공간을 나눠 쓴다 — CompCore 의 폴더를 그대로

- 상태: 채택
- 날짜: 2026-10-23
- 관련: [ADR 0008](0008-해석-작업은-건-사람의-것-게시해야-남이-본다.md)(건 사람의 것) · [ADR 0014](0014-해석-목록의-단위는-단일-해석과-DOE-한-벌이다.md)(목록이 하나가 됐다 — 폴더 · 고르기는 항목 단위) · CompCore 의 폴더(`app/shared/folders.py`, `frontend/src/shared/folders`)

## 결정

1. **폴더는 표가 따로 없다 — 작업 행이 들고 있는 경로다**(`simulations.folder`, `고객A/2026`, 맨 위는 빈
   것). 나무는 경로들에서 세운다(위 폴더도 빠짐없이, 바로 그 폴더에 있는 수). 빈 폴더는 항목을 넣기 전까지
   그 브라우저에만 있다. **CompCore 의 규칙과 코드를 그대로 옮겼다** — 경로 다듬기(`/고객A//2026/ ` →
   `고객A/2026`) · 깊이 8 · 이름 60자 · 폴더째 옮기기(하위까지 · 있으면 합치기) · 지우기는 위 폴더로 합치기.
   화면 조각(나무 · 끌어다 놓기 · 고르기 칸 · 고른 것 막대 · 폴더 창)도 같다.

2. **DOE 의 폴더는 그 설계점 작업들의 폴더다.** 스터디는 행이 아니다(작업 표에서 모은다) — 그래서 DOE 를
   옮기면 그 설계점 작업들(앞선 시도까지, 내가 건 점)이 옮겨 가고, DOE 목록은 주인의 점이 가장 많이 놓인
   폴더에 그 DOE 를 둔다. **해석 작업 목록과 DOE 목록이 한 폴더 공간이다** — 「고객A」 에 작업도 DOE 도
   든다. 나무의 수는 목록마다 따로 센다(작업 수 · DOE 수). 폴더 이름 바꾸기 · 지우기는 둘에 함께 미친다.

3. **옮기기는 건 사람 · 시스템 관리자, 폴더째 옮기기는 내 작업만.** 하나라도 못 옮기면(안 보이거나 남의
   것) 아무것도 옮기지 않는다. 폴더 이름 바꾸기는 그 폴더 아래의 **내 작업만** 옮긴다 — 공용 작업공간에서 남의
   게시 작업이 같은 이름의 폴더에 있어도 그대로다(폴더는 사람이 제 것을 나누는 자리다).

4. **여럿 고르기(체크박스)** — 목록에서 바꿀 수 있는 줄(내 것, 시스템 관리자는 모두)만 고른다. 고르면
   「폴더로 이동」 · 게시 · 게시 해제 · 삭제를 한꺼번에. 게시 · 해제 · 삭제는 **낱개 API 를 하나씩** 부르고
   못 한 것은 까닭을 모아 말한다(끝나지 않은 작업은 게시가 안 되고, 도는 작업은 지우지 않는다 — 서버가 판정한다).

## 배경

해석 작업 · DOE 목록이 한 줄로만 쌓였다 — DOE 몇 벌이면 설계점 작업이 수백 줄이고, 게시 · 지우기는 하나씩
눌러야 했다(2026-10-23 요청: 「여러 게시를 체크박스로 선택」 · 「작업 리스트에 폴더 구조」). CompCore 에는 이미
같은 일(내 작업 · 부품 · 지그 · 템플릿의 폴더 · 고르기)이 있고, 같은 사람이 두 플랫폼을 오간다.

## 대안

- **폴더 표를 따로 둔다** — 빈 폴더를 서버에 남길 수 있지만, 항목과 폴더 표가 어긋나는 자리가 하나 더
  생긴다(지운 폴더에 든 항목). CompCore 가 같은 이유로 버렸다.
- **DOE 는 따로 폴더를 둔다**(`source_meta` 에) — 해석 작업 목록에서 그 설계점들이 어디 있는지와 DOE 가
  어디 있는지가 갈린다. 한 공간이면 「고객A 의 것」 이 두 목록에서 같다.
- **고른 것을 한 번에 처리하는 API** — 요청은 줄지만 권한 · 상태 판정을 두 벌 둔다. 한 쪽(50줄)이면 하나씩
  불러도 충분하다. 많아지면 그때 묶음 API 를 더한다.

## 결과

- 마이그레이션 `0011_simulation_folder` — 칸 하나(기본 빈 것), 있던 작업은 모두 맨 위.
- API: `GET /simulations/folders` · `POST /simulations/move` · `POST /simulations/folders/rename` ·
  `GET /simulations/studies/folders` · `POST /simulations/studies/move`, 목록 둘에 `folder` 거르개
  (빈 것 = 폴더에 넣지 않은 것, 경로 = 그 폴더와 그 아래).
- MCP 에는 아직 폴더 도구가 없다(화면에서 나눈다).
