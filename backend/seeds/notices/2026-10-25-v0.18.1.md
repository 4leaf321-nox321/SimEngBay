# v0.18.1 업데이트 — CalculiX 모달 DOE 에도 모드 지도가 그려지고, 여러 변수 DOE 를 바르게 견줍니다

■ 새로 생긴 것
- CalculiX 결과에도 모드 지문이 실려 모달 DOE 의 「모드 지도」 가 그려집니다. 전에는 Ansys 결과에만 있어 CalculiX 모달 DOE 의 모드 지도가 늘 비었습니다.
- 최적점 찾기에서 목표와 조건을 직접 고릅니다. 목표 하나(크게 · 작게 — 맨 앞이 「최적」)나 둘(파레토 — 「후보」)과 조건 여러 줄(예: 「질량 ≤ 40 g」 · 「재료 = SS400」)을 고르면 표가 바로 바뀝니다.
- 그림에 설계점 이름이 나옵니다. 툴팁이 「p0002 · 2차」 처럼 이름부터 말하고, 질량 대 주파수 그림은 점 옆에 이름을 적습니다.
- 「다변수」 탭에서 색 막대의 색 지도(Ansys 무지개 · Turbo · Jet · Viridis 등)를 고릅니다. 값 그림 · 상관 그림 · 3D 뷰어의 선택은 따로 기억합니다.

■ 바뀐 것
- 설계 변수가 여럿인 DOE 요약은 두 끝 점을 견주지 않고, 변수마다 훑은 범위 · 결과의 최소 ~ 최대와 그 점 · 「가장 크게 움직인 변수」 를 적습니다. 모달 · 정적 · 조화 비교 탭 모두 같습니다.
- 모드 지도 · 값 그림은 나머지 변수를 고정한 단면(예: 폭 = 20)만 선으로 잇고, 「고정 안 함」 이면 점만 찍습니다. 처음 가로축은 그 결과를 가장 크게 움직이는 변수입니다.
- 같은 모드를 못 이은 자리(—)에 까닭과 할 일을 적습니다. 닮은 모드가 없으면(대개 위로 밀려남) DOE 를 지우고 모드 수 10개로 다시 가져오라고, 모양이 바뀌었거나 섞였으면 형상을 직접 보라고 안내합니다.
- DOE 를 가져올 때 모드 수를 주지 않으면 CAD 가 적은 값을, 그것도 없으면 10 을 씁니다. 비교하는 수(6) 이하로 구하면 가져오기와 새 해석 창이 「끊길 수 있다 — 10개 권장」 이라고 알립니다(막지는 않습니다).

■ 확인해 주십시오
- 이미 끝난 CalculiX 모달 DOE 에는 지문이 없습니다. 다시 걸어야 모드 지도가 그려지며, 화면도 그렇게 알려 줍니다.
- DOE 가져오기 응답에 안내 항목이 더해졌지만, 있던 연동 호출은 그대로 돕니다.
- v0.18.0 은 게시되지 않았고, 이 판이 v0.18.0 의 기능을 모두 담습니다.
