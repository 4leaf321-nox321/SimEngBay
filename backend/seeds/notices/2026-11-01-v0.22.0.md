# v0.22.0 업데이트 — CalculiX 로 압축 전용 지지와 마찰판 볼트 조립을 풉니다

■ 새로 생긴 것
- CalculiX 로 압축 전용 지지를 겁니다. 정적에서는 한쪽이 들리는 것까지 풀고, 이제 CalculiX 가 못 거는 구속 종류가 없습니다.
- CalculiX 로 판 사이 마찰이 있는 볼트 조립을 끝까지 풉니다. 끝의 볼트 힘이 Ansys 와 0.07 % 안에서 맞고, 스레드 2개로 점마다 30분 남짓 걸립니다.

■ 바뀐 것
- Ansys 탄성 지지의 반력이 늘 0 으로 나오던 것을 고쳤습니다. 기둥 끝 탄성 지지에서 CalculiX 와 0.4 % 안에서 맞습니다.
- 마찰면을 가른 모델에서도 측정점이 제자리를 따라갑니다. 전단 이음 폴더의 마찰 점도 이 방식으로 풀리며 판정은 그대로입니다.

■ 확인해 주십시오
- CalculiX 압축 전용 지지는 정적에서 큰 변형 단계로 풀어 들림을 따지므로, 가늘고 눌린 부재는 그만큼 변위가 커집니다(하중 10배에서 4.5 %). 모달 · 조화는 닿은 채로 풀고 그렇게 풀었다고 적습니다(Ansys 도 처음 닿은 상태로 풉니다).
- Ansys 의 압축 전용 지지 반력은 읽지 않습니다. 수렴 오차가 커서(100 N 에 112.6 N) 믿을 수 없기 때문입니다.
- 조임량으로 건 마찰판 볼트는 CalculiX 접촉이 더 단단해 볼트 힘이 Ansys 와 3 ~ 4 % 다를 수 있습니다.
