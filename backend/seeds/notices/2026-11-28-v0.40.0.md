# v0.40.0 업데이트 — 소성 재료로 푼 DOE 에서 소성 변형률을 설계점끼리 견줍니다

■ 새로 생긴 것
- 소성 재료로 푼 정적 DOE 에서 **최대 등가 소성 변형률**을 견줄 값으로 봅니다. DOE 비교의 그래프 · 표, CSV 의 「최대 등가 소성 변형률」 열, DOE 분석(MCP 포함)의 목표 · 조건에 쓸 수 있습니다(예: 소성 변형률 0.5 % 아래에서 가장 얇은 설계점).
- 메시 수렴 점검에서도 이 값을 판정합니다. 상당응력처럼 구속 모서리 · 날카로운 모서리에 몰리면 메시를 줄일수록 커지므로, 수렴하지 않으면 그렇다는 알림을 붙입니다. 모든 수준에서 0.01 % 아래면(항복 문턱 언저리) 수렴으로 봅니다.
- MCP 의 결과 숫자에도 최대 등가 소성 변형률이 실립니다.

■ 바뀐 것
- Ansys: 소성 재료로 풀고 항복하지 않은 정적 결과에 최대 등가 소성 변형률 0 을 적습니다(앞 판은 비워 두었습니다 — CalculiX 와 같게). 소성 변형률을 읽지 못하면 0 으로 적지 않고, 결과 화면 위에 그렇다는 알림을 띄웁니다.
- 단위가 없는 값은 이름 뒤에 빈 괄호를 붙이지 않습니다.

■ 확인해 주십시오
- 값은 하중 단계 · 해석 케이스가 있으면 마지막 단계 끝의 값입니다(최대 상당응력과 같은 규칙). 등가 소성 변형률은 줄지 않으므로 보통 단계 전체의 최대와 같습니다.
- 소성 재료로 풀었는데 항복하지 않은 설계점은 0 입니다(두 솔버 같음). 탄성 재료로 푼 설계점과 값을 읽지 못한 설계점은 비어 있고, 조건으로 고를 때 빠집니다. 탄성 재료로만 푼 DOE 에는 이 열이 나오지 않습니다.
- CalculiX 와 Ansys 는 적분점 값을 절점으로 옮기는 방식이 달라 최댓값이 조금 다를 수 있습니다. 두 솔버를 섞어 견주지 마십시오.
