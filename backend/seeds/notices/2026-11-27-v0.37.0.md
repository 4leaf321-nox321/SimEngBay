# v0.37.0 업데이트 — 해석 케이스로 나눈 CAD 조건을 받습니다

■ 새로 생긴 것
- CompCore 에서 해석 케이스(앞 케이스 → 뒤 케이스)로 나눈 조건을 받습니다. 이어진 케이스 한 줄(사슬)이 작업 하나가 되고, 끝 케이스의 해석 종류로 풉니다.
- 정적 케이스를 여럿 이은 사슬(정적 다단)을 CalculiX · Ansys 둘 다로 풉니다. 뒤 케이스는 앞 케이스가 끝난 상태에서 시작하고, 하중은 이어지지 않습니다(조인 볼트만 그 길이로 잠긴 채 이어집니다).
- 정적 결과에 **케이스마다 끝 상태** 표(최대 변형 · 상당응력 · 반력 · 볼트 힘)가 생겼습니다.
- 새 작업 · DOE 가져오기 창에서 점의 사슬을 고를 수 있습니다. 여러 점을 한 번에 가져오면 사슬마다 작업이 됩니다.
- 스터디 · 비교 표 · CSV 는 케이스 하나씩 봅니다(「해석 케이스」 단추).

■ 바뀐 것
- 앞 정적의 설정(큰 변형 · 초기 부단계)이 기본값이 아닌 「정적 → 모달」 사슬도, 앞 정적의 하중과 설정을 그대로 건 선응력 모달로 풉니다.
- 해석 쪽 능력표가 해석 케이스를 받는다고 알리고, 해석마다 앞 케이스로 올 수 있는 해석을 함께 싣습니다.

■ 확인해 주십시오
- 갱신 중(한 서버만 새 판일 때) 만든 해석 케이스 작업은 두 서버가 다 새 판이 된 뒤 다시 돌리십시오.
- 능력표의 CalculiX 판은 이 서버의 로컬 워커가 잰 판입니다. STE 는 CalculiX 판이 같을 때만 고를 수 있습니다.
- CalculiX: 큰 변형에서 면이 모멘트 축 둘레로 크게 돌면 모멘트가 줄어듭니다(10° 면 1.5 %, 30° 면 13 % 모자람). Ansys 는 해당 없습니다.
